# MCP Go Roadmap

## Quarter 1 2026: Protocol Compliance

- [ ] **SSE Transport**: Full implementation of Server-Sent Events transport for MCP.

- [ ] **Sampling Support**: Implement the MCP 'sampling' capability for agent-initiated interactions.
